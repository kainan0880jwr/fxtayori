# FXたより — 公開ページ

iOS / Android アプリ「FXたより」のプライバシーポリシー・利用規約を公開しています。

| ページ | 用途 |
|---|---|
| `index.html` | トップ。アプリの説明と各文書への導線 |
| `privacy.html` | プライバシーポリシー（ストア審査の必須項目） |
| `terms.html` | 利用規約 |

## 編集について

これらのHTMLは `FXニュース/output/legal/site/` が原本です。
事業者名・連絡先・制定日は `output/legal/apply_operator.py` で一括反映しています。
**直接編集せず、スクリプト経由で更新してください**（アプリ内の表記と食い違うため）。
